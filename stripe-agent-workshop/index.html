问题本质 · 生成结构化产物

这张图必须同时经得住三套系统的检验。

01Schema每种节点都要求不同的 data 结构。字段错误 → 草稿无法加载
02CanvasReactFlow 的边依赖 Source 与 Target Handle。Handle 错误 → 出现悬空边
03Runtime变量需要跨越整张图引用节点输出。引用失效 → 运行时输出占位文本
生成可以是概率性的，但“能不能加载”不可以。
时间 19:00–21:00。核心讲法：Workflow DSL 会被三套系统消费：Schema 校验、视觉画布和执行运行时。悄悄产生错误的情况，往往比直接解析失败更危险。术语解释：Handle 是一条边连接节点时使用的命名连接点。过渡句：因此架构必须把语义不确定性与结构保证分开。证据边界：这些例子描述 Dify Workflow 图的约束，不能直接推广到所有 DSL。
