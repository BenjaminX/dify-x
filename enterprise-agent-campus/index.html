Autonomy Runway · 三阶段放权

放权的是“稳定动作”，不是 Agent 的身份。

01 · OBSERVE

旁路观察与草稿

只读、建议、对比人工结果。

02 · CONFIRM

人工确认后执行

每次工具动作都有明确批准。

03 · AUTO

低风险动作自动执行

只开放已证明稳定且可回退的部分。

更多人工介入证据不足随时降级 ←更少但不消失
时长 2:00。核心讲法：三阶段按证据晋级，不按日历；线上漂移后可以降级。术语：旁路观察是不改变真实流程，只比较 Agent 与人工。过渡：晋级需要同时通过业务和安全两组验收。证据边界：第三阶段并非全自动，只适用于稳定、低风险、可回退动作。
