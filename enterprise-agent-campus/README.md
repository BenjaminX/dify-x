# 企业 Agent：从能力边界到系统落地

面向大一与研一新生的 45 分钟 Reveal.js 双语讲座。新版不再罗列场景或堆叠控制清单，而是围绕一个退款率异常分析任务，讲清企业如何把工作委派给 Agent，并保留权限、证据和停止责任。

## 演示入口

- 中文：`index.html`
- English: `index_en.html`
- 讲者模式：按 `S`
- 总览：按 `Esc`
- PDF：在 URL 后添加 `?print-pdf`

从仓库根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000/enterprise-agent-campus/`。

## 新论证链

1. 委派不是“让模型回答”，而是授予决策权、资源和责任路径。
2. Agent 是任务契约内的闭环执行者：观察、行动、验证、停止。
3. 用“动作半径 × 不可逆性 × 发现延迟”讨论暴露，用“可验证 × 可回退”筛选起点。
4. 把确定步骤固定为 Workflow，只在局部不确定性中开放受限 Agent loop。
5. 用任务契约、工具契约和证据契约将行为变成可检查条件。
6. 用上下文栈、工具边界、证据账本、决策权和持续评测组成企业控制系统。
7. 通过退款分析推演验证：可靠系统不仅会继续，也知道何时澄清、修正或停止。

每页讲者备注都包含建议时长、核心讲法、术语、过渡句和证据边界。

## 文件结构

- `index.html`：中文母版，20 页。
- `index_en.html`：英文等义镜像版，20 页。
- `styles.css`：1920×1080 共用视觉系统。
- `source-map.md`：逐页依据、证据边界、公开来源和图片版权。
- `assets/`：本地化 Unsplash 氛围图。
- `qa/`：中英文 contact sheet。

## 视觉原则

- 一页一个判断；一个明确阅读起点；最多三个辅助信息区。
- 不使用三张以上等权卡片矩阵；用轴线、闭环、风险公式、矩阵、契约叠层、证据账本和运行轨迹表达关系。
- 相邻页面不重复同一几何结构；氛围图仅用于封面、案例转场与结尾。
- Dify Blue 表示系统路径，绿色表示可继续，琥珀表示澄清或人工确认，红色表示停止或越界。
- 正文不低于约 30px，引用不低于 17px；打印与减少动态效果模式完整呈现所有 fragment。

## 内容接口

中英文页面共享 20 个 `data-slide-id`。HTML 注释继续使用：

- `REPORT_SLOT`：研究结论与证据边界。
- `CASE_SLOT`：任务、状态、动作、人工控制和风险。
- `VISUAL_SLOT`：图片、图表和版权信息。

## 后续研究接入

新增材料优先回答：

1. 任务完成条件能否被机器和人共同检查？
2. 工具权限、预算、幂等和回退如何实现？
3. 一次运行保留了哪些可重放证据？
4. 哪类异常必须停止并交给谁？
5. 评测如何覆盖正常路径、异常样本、权限和持续漂移？

不要为了容纳新材料恢复场景清单或案例堆叠。完整来源规则见 `source-map.md`。
