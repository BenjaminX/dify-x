# 企业 Agent：从能力边界到系统落地

面向大一与研一新生的 45 分钟 Reveal.js 校园讲座。中文和英文版本共享 20 页结构：30 分钟框架、10 分钟企业数据分析推演、5 分钟问答。

## 打开演示

- 中文：`index.html`
- English: `index_en.html`
- 讲者模式：按 `S`
- 总览：按 `Esc`
- PDF：在 URL 后添加 `?print-pdf` 后打印

推荐从仓库根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：

- `http://localhost:8000/enterprise-agent-campus/`
- `http://localhost:8000/enterprise-agent-campus/index_en.html`

## 文件结构

- `index.html`：中文母版，20 页
- `index_en.html`：英文等义镜像版，20 页
- `styles.css`：1920×1080、12 栏基础与非卡片视觉组件
- `source-map.md`：研究依据、证据等级、旧页映射和图片版权
- `assets/`：本地 Unsplash 氛围图
- `qa/`：中英文 contact sheet

## 视觉原则

1. 每页只推进一个完整判断，并提供一个明确的阅读起点。
2. 不使用三张以上等权矩形并排；卡片只用于展示真实 UI 对象。
3. 复杂信息使用连续路径、系统剖面、阶段门、双轨或控制边界表达。
4. 相邻页面不重复同一几何结构；氛围图只用于封面、场景转场、案例开场和结尾。
5. 每个复杂页面最多 2–4 轮渐进揭示；动画关闭或打印时信息仍完整。
6. Dify Blue 表示系统主路径，绿色表示可继续，琥珀表示人工确认，红色表示停止或不可逆风险。

## 内容接口

中英文页面必须共享相同 `data-slide-id`、事实顺序和来源。HTML 中保留三类插槽：

- `REPORT_SLOT`：研究结论、证据等级和研究章节
- `CASE_SLOT`：任务、系统、Agent 链路、人工控制、KPI 和风险
- `VISUAL_SLOT`：图表、产品截图或版权图片

每页讲者备注包含：建议时长、核心讲法、术语解释、过渡句、证据边界。当前时长严格合计为：

- `s01`–`s16`：30:00
- `s17`–`s19`：10:00
- `s20`：5:00

## 证据规则

- `A`：实名案例并披露明确结果指标。
- `B`：实名工程实践或官方实现参考，但缺少可比较结果指标。
- `Internal Signal`：内部访谈或内部研究信号。
- 研究综合判断不使用旧版 `REPORT` 徽章。
- 所有供应商数字必须保留“来源方披露、未独立审计”。
- 外部企业案例不得被描述为 Dify 客户案例。
- 数据分析案例始终标记为合成静态教学推演。

## 讲者准备

1. 替换封面和结束页的讲者、学校、日期与联系方式。
2. 用讲者模式完成一次 30/10/5 计时走读。
3. 若超时，先缩短合同和客服案例背景，不删除停止条件、八项控制或人工边界。
4. 后续研究优先补充真实基线、异常样本、专家修改量和流程 owner，不追加大量案例。
